<br>

* **What is the difference between @State and var?**

  *@State creates a variable that updates the UI when it changes. A var is just a regular variable so changing it does not update the view.*

* **Why do we reset hour to 0 after 24?**

  *Because clocks use a 24-hour cycle. After hour 23 to the next hour should loop back to 0, starting a new day.*

* **How does abstraction help in controlling the minute hand?**

  *Abstraction means hiding details and focusing on the essential idea. Instead of manually adjusting positions or angles, you use a simplified concept like “minute value” to control the hand. This makes the code easier to manage.*

* **How is .onTapGesture similar to Scratch’s event blocks?**

  *Both react to user actions. .onTapGesture runs code when the user taps.*

* **How is using minuteSeg an example of abstraction in programming?**

  *minuteSeg represents a simple input (0–59) that controls a more complex behavior, like rotating the minute hand. Takes away the worry of math and angles.

* **How is a Button different from .onTapGesture?**

*A Button is a built-in UI element designed for tapping, with automatic features like animations and accessibility.
.onTapGesture can be added to any view, but it doesn’t include those built-in button behaviors.*

* **Why might we want multiple input methods?**

*Different input methods make the app more flexible and accessible. Some users may prefer tapping, others sliding etc. More options mean a better experience.*

* **Which input felt most natural to you? Why?**

*Tapping because it felt the easiest, fastest and most intuitive, especially for quixk actions. But, other inputs like dragging might be more suitable for actions that require preise control.*

* **How does this show event-driven programming?**

*The app reacts to what the user does; taps, drags, or presses. Each action triggers an event, and the program responds, which is how event driven programming works.*

* **Define in your own words...**

**Lossless compression** =
*Compression that reduces file size without losing any information. The original file can be perfectly restored.*

**Lossy compression** =
*Compression that removes some data to make the file much smaller. The original file cannot be perfectly restored, but the result still looks or sounds good.*

* **What is metadata? Give one example.**

*Metadata is data about data; information that describes a file.
**Example:** the date a photo was taken, file size, or camera type.*

* **How can metadata help organize or filter data?**

*Metadata lets us sort, group, or search through data more easily. For example, you can sort photos by date, filter files by type, or search documents by author.*
